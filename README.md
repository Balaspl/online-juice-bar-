# Online Juice Bar

## Description

Online Juice Bar is a responsive front-end website developed using HTML, CSS, and Bootstrap. 
The project provides a modern and attractive user interface for a juice shop, allowing users to browse different juice items through a clean and user-friendly design. 
This project focuses on front-end development and responsive web design.

## Features

- Responsive website design
- Modern and attractive user interface
- Home page with juice products
- Navigation bar
- Mobile-friendly layout
- Bootstrap components
- Clean and simple design

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5

## Project Type

Front-End Web Development (UI Only)
